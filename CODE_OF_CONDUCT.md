# Code of Conduct

We are committed to a welcoming, harassment-free community. Be respectful, considerate and constructive; accept feedback in good faith. Harassment, discrimination, threats, publication of private information, and other abusive conduct are unacceptable.

Maintainers may remove comments, reject contributions, or restrict participation to protect the community. Report incidents privately to a repository maintainer through a GitHub private security advisory. Maintainers should handle reports confidentially and fairly.
